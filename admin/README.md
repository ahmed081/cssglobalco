# CSS Global Recruit — React TS UI Prototype

UI-only React + TypeScript implementation based on the provided HTML.

## Included

- Reusable React components
- Redux Toolkit store
- Redux-Saga persistence layer
- Static demo data for preview
- Dashboard analytics UI
- Roles module with richer cards and edit modal
- Pipeline module with move/back/reject actions
- Candidates module with working filters, sorting, bulk actions, and mobile cards
- Candidate profile with stage history, attachments, client-safe notes, share/PDF preview actions
- Interview schedule preview
- No backend integration

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
